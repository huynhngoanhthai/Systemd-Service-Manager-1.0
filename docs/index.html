Hướng Dẫn Cài Đặt & Sử Dụng

Các bước đưa plugin vào aaPanel của bạn nhanh chóng chỉ trong 2 phút.

1

Tải mã nguồn plugin vào máy chủ

Đăng nhập SSH máy chủ Linux, chuyển tới thư mục plugin của aaPanel và giải nén hoặc clone repository:

cd /www/server/panel/plugin
# Clone hoặc tải zip plugin Systemd-Service-Manager vào thư mục này
2

Chạy script cài đặt (install.sh)

Chạy lệnh shell để cấp quyền và khởi tạo cấu hình cho aaPanel:

cd /www/server/panel/plugin/systemd_manager
bash install.sh install
3

Mở plugin từ giao diện aaPanel

Mở aaPanel Web UI > App Store > danh mục Third-party app để bắt đầu quản lý các dịch vụ một cách trực quan.

Mẫu Cấu Hình Systemd Tiêu Chuẩn

Sao chép nhanh các cấu hình phổ biến để dán vào tab Raw Unit của plugin.

📦 Node.js / Next.js / Express

[Unit]
Description=Node.js Production Application
After=network.target

[Service]
Type=simple
User=www
WorkingDirectory=/www/wwwroot/my-node-app
ExecStart=/usr/bin/npm start
Restart=always
RestartSec=5
Environment=NODE_ENV=production PORT=3000

[Install]
WantedBy=multi-user.target

🐍 Python / FastAPI / Odoo Instance

[Unit]
Description=FastAPI / Uvicorn Service
After=network.target

[Service]
Type=simple
User=www
WorkingDirectory=/www/wwwroot/my-api
ExecStart=/www/wwwroot/my-api/venv/bin/uvicorn main:app --host 127.0.0.1 --port 8000
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target

Thêm Dịch Vụ Mới (Add Systemd Service)

journalctl -u service -n 50 --no-pager
Nhấn "Làm mới" để kéo các log mới nhất từ server
